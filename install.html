Install on each kind of device

🤖 Android phone / tablet (Chrome)

  1. Open the client app link above in Chrome.
  2. Tap the green Install SemaChat bar at the bottom (or ⋮ menu → Install app).
  3. Open it from the home screen: the globe animation plays, then the app.

🍎 iPhone / iPad (Safari)

  1. Open the client app link in Safari (not inside another app).
  2. Tap Share ⬆️, then Add to Home Screen, then Add.

💻 Windows / Mac / Linux (Chrome or Edge)

  1. Open the client app or the console.
  2. Click the install icon ⊕ at the right end of the address bar (or the green bar), then Install.
  3. It opens in its own window and appears in your Start menu / Applications.

Two apps, two icons

Install the client app and the developer console separately: each gets its own icon and window, so you can test both side by side.

Signing in (development)
